Stokasir

Aplikasi manajemen stok-kasir grosir/eceran — multi-toko, multi-cabang, multi-dialect DB. Webview lokal (LAN/Pi) atau cloud.

Repo: memuat…

Overview

Backend — Bun + Hono REST API (port 3000). Drizzle ORM multi-dialect (SQLite/Turso/Postgres/MySQL). Modul: SOP engine, event bus, attachment, approval, scheduler, storage driver, backup/restore. Dok API live di Scalar.

Frontend — SvelteKit + Vite (port 5173), webview ringan. Mode deploy: jika LAN/offline (host/ maka ke kasir) atau jika cloud (host/ maka ke landing). Multi-tenant SaaS: onboarding, daftar, picker toko.
